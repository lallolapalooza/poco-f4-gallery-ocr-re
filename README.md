This is a reverse engineering project for the gallery app in the Xiaomi Poco f4. The poco f4 phone has OCR with labeling and position detection on the gallery app. Provided is a full reimplementation of 
the OCR pipeline with the OCR model extracted from the gallery app APK. 

This phone has been abandoned by the manufacturer. 

the gallery app APK was extracted from a stock unrooted poco f4 by telling an ai agent, oh my pi with DeepSeek v4 flash to copy the root filesystem over adb without the sdcard or storage directories and ignoring all access denied folders.
